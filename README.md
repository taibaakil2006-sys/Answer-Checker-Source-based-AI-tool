# Answer-Checker-Source-based-AI-tool
A trustworthy question-answering tool that answers only from provided sources and refuses when the available evidence is insufficient.
## Features

- Source-based question answering
- Keyword-based passage matching
- Confidence threshold
- "I don't know" refusal when evidence is insufficient
- Source identification
- Evaluation across multiple thresholds
- Designed to reduce unsupported answers
